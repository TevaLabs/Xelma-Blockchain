# Quality: distinguish close-buffer and bet-end errors

Closes #510.

## Summary

- Add `ContractError::BettingClosed` (code `102`) for bets rejected by the configured close buffer.
- Keep `ContractError::RoundEnded` (code `8`) for attempts at or after `bet_end_ledger`.
- Apply the distinction to Up/Down bets, direct Precision predictions, and Precision commits.
- Update TypeScript bindings and both contract-error wallet registries.

`102` is the next unused error code. Existing codes, including `66` for
`OracleTimestampOutsideWindow`, remain unchanged.

## Tests

- `npm run test:errors`
- `npm run lint`
- `git diff --check`

The focused Rust command, `cargo test -p xelma-contract close_buffer`, could
not finish in the local environment because compiling the cold Soroban dependency
stack exceeded the five-minute command limit. The close-buffer boundary tests
cover each affected entry point and assert both `BettingClosed` and `RoundEnded`.
